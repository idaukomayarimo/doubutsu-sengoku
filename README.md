# どうぶつ戦国 陣取り合戦

1台のスマホを交互に持って遊ぶ、動物武将たちの合戦ゲームです。部隊を並べて命令を出すと、部隊が命令どおりに自動で戦います。

**遊ぶ**：https://idaukomayarimo.github.io/doubutsu-sengoku/

## 遊び方

1. 武将を選ぶ（赤の陣 → 青の陣）。
2. **布陣**：自分の陣地（手前3列）に部隊を並べ、最初の命令を決める。
3. 自分の番は、部隊に**命令**を出して「行動開始」。全部隊が命令どおりに**自動で**動き、変えるまで同じ命令を続ける。1ターンに命令を変えられるのは**采配**の数まで。
4. 相手の軍勢を**全滅**させたら勝ち。**50ターン**（各50回）で決着しなければ得点で勝負（領地1点・城5点・残った兵10人で1点）。

### 命令と兵種
| 命令 | 動き |
|---|---|
| ➡️ 進軍 | 目的地へ向かう。着いたら守備に切り替わる（騎馬はその場で待機） |
| ⚔️ 攻撃 | 敵を追いかけて攻撃する（狙う敵を選ぶか、一番近い敵） |
| 🛡️ 守備 | その場で守る（受けるダメージ 2/3） |
| 🏯 占領 | 一番近い、自分のでない城を取りに行く |

| 兵種 | 移動 | 射程 | できないこと |
|---|---|---|---|
| 🚩 本陣（武将） | 1 | 1 | 占領。倒されると技が使えない |
| 🗡️ 足軽 | 1 | 1 | なし（万能だが遅い） |
| 🐎 騎馬 | 2 | 1 | 山・森に入れない。守備・占領。動いてから攻撃すると 1.5倍 |
| 🔫 鉄砲 | 1 | 2 | 動いた番は撃てない。隣に敵がいると撃てない |
| 🏹 弓 | 1 | 2 | 占領 |

### 武将
| 武将 | 軍勢 | 采配 | 技（1回） |
|---|---|---|---|
| 🐱 のぶネコ（織田信長） | 260（鉄砲が多い） | 2 | 🔫 三段撃ち：鉄砲が動いても撃てて 1.5倍 |
| 🐯 しんタイガー（武田信玄） | 270（騎馬が多い） | 2 | 🔥 風林火山：移動+1、次の番まで守りも固い |
| 🦝 いえタヌキ（徳川家康） | 300（大軍勢） | 2 | 🍃 狸の二段構え：全部隊が2回行動 |
| 🐵 ひでザル（豊臣秀吉） | 240（部隊が多い） | 3 | 🔨 墨俣一夜城：味方の隣に城を建てる |

### 地形・アイテム
- 🏯 城（10個）：5点。上にいる自分の部隊は毎ターン兵+5。🌲 森：守りやすい。⛰️ 山：通れない。
- 通ったマスは自分の領地。自分の色で囲むと中も取れる。
- 5ターンごとにアイテム出現：🍙兵糧（兵+30）・📯援軍（足軽30が城に出る）・💥火薬（次の攻撃2倍）・📜軍配（次の番の采配+2）

スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように全画面で遊べます。一度開けば電波がなくても遊べます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面の骨組みと合戦画面の見た目 |
| `battle.js` | 合戦のルール（画面なし）。布陣・命令・自動行動・戦闘・占領・包囲・アイテム・技・得点 |
| `units.js` | 兵種（能力とできないこと）と命令 |
| `generals.js` | 武将の名簿・編成・采配（ここに1件足すと選択画面に並ぶ） |
| `skills.js` | 武将の技の説明 |
| `hex.js` / `terrain.js` | ヘクス座標の計算／地形とランダムマップ生成 |
| `render.js` | 盤面の描画 |
| `panel.js` | 画面下の命令パネル |
| `screens.js` / `screens.css` | 武将選択・交代・結果・確認の画面 |
| `sound.js` | 効果音（Web Audio で合成）と振動 |
| `game.js` | 上をつなぐ司令塔（操作・アニメーション・手番の流れ） |
| `manifest.webmanifest` / `sw.js` / `icons/` | ホーム画面への追加とオフライン対応 |
| `tests/` | ルールのテスト（ブラウザで `tests/index.html` を開くと実行） |
| `docs/v2-design.md` | v2 の設計 |
| `tools/` | 開発用（ローカルサーバー、claude.ai 公開用ビルド）。ゲーム本体には不要 |

## 数値の調整

- 兵種の強さ・制約：`units.js`
- 武将の編成・采配：`generals.js`
- ターン数・回復量・アイテムの頻度など：`battle.js` の `CONFIG`
- 城・山・森の数：`terrain.js` の `MAP_RECIPE`

## イラスト・音の差し替え

- 武将の絵：`generals.js` の `sprite` に PNG のパス
- 地形の絵：`terrain.js` の `sprite` に PNG のパス
- 効果音：`sound.js` の `SOUND_FILES` に音声ファイルのパス

## 更新するとき

ファイルを直して公開し直したら、**`sw.js` の `CACHE_VERSION` を1つ上げる**こと（上げないとスマホに古い版が残ります）。
新しいファイルを足したときは、`sw.js` の `APP_FILES` にも追加します。

## 手元で動かす（開発用）

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1 -Root . -Port 8190
```

ブラウザで http://localhost:8190/ を開きます（テストは http://localhost:8190/tests/）。localhost ではオフライン対応を切っています（`?sw` を付けると有効）。
