# どうぶつ戦国 陣取り合戦

1台のスマホを交互に持って遊ぶ、ヘクスマップの陣取りゲームです。動物の武将を選んで、20手のあいだに得点の多い方が勝ち。

## 遊び方

- 交互に、武将の**隣のマス**へ移動します。通ったマスが自分の領地になります。
- 自分の色で**ぐるっと囲む**と、中のマスが一気に自分のものになります（外周に触れている所・武将がいる所は除く）。
- 🏯 城は1マス**3点**。⛰️ 山は通れませんが、囲むときの壁になります。
- 武将ごとの**技**は1回だけ使えます。

| 武将 | 技 |
|---|---|
| 🐱 のぶネコ（織田信長） | 🐾 ねこまた大跳躍：2マス先まで跳ぶ（山も越える） |
| 🐯 しんタイガー（武田信玄） | 🔥 風林火山の咆哮：周り6マスを一気に塗る |
| 🦝 いえタヌキ（徳川家康） | 🍃 狸の二段構え：2回続けて動く |
| 🐵 ひでザル（豊臣秀吉） | 🔨 墨俣一夜城：隣の平地に城を建てる |

スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように全画面で遊べます。一度開けば電波がなくても遊べます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みと基本の見た目 |
| `game.js` | ルール・盤面の描画・タップ操作 |
| `hex.js` | ヘクス座標の計算（隣接・距離・点対称） |
| `terrain.js` | 地形（城・山）とランダムマップ生成 |
| `generals.js` | 武将の名簿（ここに1件足すと選択画面に並ぶ） |
| `skills.js` | 武将の技 |
| `screens.js` / `screens.css` | 武将選択画面・結果画面・確認画面 |
| `sound.js` | 効果音（Web Audio で合成）と振動 |
| `manifest.webmanifest` / `sw.js` / `icons/` | ホーム画面への追加とオフライン対応 |
| `tools/` | 開発用（ローカルサーバー、claude.ai 公開用ビルド）。ゲーム本体には不要 |

## イラスト・音の差し替え

- 武将の絵：`generals.js` の `sprite` に PNG のパス
- 地形の絵：`terrain.js` の `sprite` に PNG のパス
- 領地の塗り：`game.js` の `TILE_SPRITES`
- 効果音：`sound.js` の `SOUND_FILES` に音声ファイルのパス

## 更新するとき

ファイルを直して公開し直したら、**`sw.js` の `CACHE_VERSION` を1つ上げる**こと（上げないとスマホに古い版が残ります）。

## 手元で動かす（開発用）

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1 -Root . -Port 8767
```

ブラウザで http://localhost:8767/ を開きます。localhost ではオフライン対応を切っています（`?sw` を付けると有効）。
